# Encrypted Traffic Fingerprinting Research Project

This repository contains my work on **encrypted network traffic fingerprinting**, completed as part of a research assignment focused on understanding privacy leakage from encrypted network metadata.

The project consists of two main components:

1. Reproduction and experimentation based on the research paper **“I Can Hear Your Alexa: Voice Command Fingerprinting on Smart Home Speakers.”**
2. Independent collection of smartphone application traffic to demonstrate network traffic capture and application fingerprinting.

---

## Voice Command Fingerprinting

The first part of the project studies whether encrypted network traffic generated by smart-home speakers can reveal information about the voice commands issued by users.

Although communication between a smart speaker and cloud services is encrypted, network-level metadata such as packet sizes, packet directions, timing, traffic bursts, and traffic volume can still expose patterns associated with different voice commands.

### Experimental Pipeline

```text
PCAP Traffic
     ↓
Traffic Preprocessing
     ↓
Burst / Flow Extraction
     ↓
Feature Extraction
     ↓
Traffic Fingerprinting
     ↓
Classification
     ↓
Evaluation
```

The repository contains experiments using several traffic-fingerprinting and machine-learning approaches, including:

- LL-Jaccard
- Naive Bayes
- VNG-style traffic features
- Support Vector Machine (SVM)

Experiments were performed using traffic traces from the voice-command fingerprinting dataset.

---

## Traffic Defense Experiment

The project also contains experiments with **BluFLO**, a traffic-shaping defense designed to reduce information leakage from encrypted traffic patterns.

The purpose of this experiment is to investigate how traffic shaping affects the ability of fingerprinting techniques to identify user activity from encrypted network traces.

---

## Independent Traffic Collection

To demonstrate the ability to independently collect network traffic, I created an additional dataset using smartphone applications.

Traffic was captured using **Wireshark** on a laptop while a smartphone connected to the same Wi-Fi network generated application traffic.

To minimize unrelated background traffic:

- Notifications were disabled
- Background applications were closed
- Applications were executed individually
- Each application was captured for approximately 90 seconds

Traffic traces were collected for:

- Amazon
- Hulu
- Instagram
- LinkedIn
- Ludo
- Maps
- Play Store
- Substack
- WhatsApp
- YouTube

Each trace is stored in `.pcapng` format. The collected dataset contains approximately **10 traffic traces totaling ~689 MB**.

## Research Motivation

Encryption protects the **contents** of network communication, but it does not necessarily hide all information about communication behavior.

Observable metadata such as packet size, direction, timing, and burst patterns can potentially reveal information about the application or user action that generated the traffic.

This project explores that privacy problem through practical encrypted-traffic fingerprinting experiments and traffic-defense analysis.
